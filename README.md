# Protocol Z: Origins

Page immersive de présentation du lore du serveur GTA RP Protocol Z: Origins.

## Publication GitHub Pages

Déposez ces fichiers dans un dépôt GitHub public, puis ouvrez **Settings → Pages** et sélectionnez la branche `main` et le dossier `/ (root)` comme source.

Site statique sans dépendances de build. Les polices DM Sans et DM Mono se chargent depuis Google Fonts ; le site reste lisible avec les polices de secours si elles ne sont pas disponibles.
